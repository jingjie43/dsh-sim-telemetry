## 二、更新日志正文（长版 · 发专栏 / 动态图文）

> 标题：**dsh-sim-telemetry 0.2.3 更新：从「报圈速」到「比赛工程师」**

```
上一版它只会告诉你「这圈 1:30.8」。
0.2.3 开始，它会告诉你「第 13 弯刹车踩重了、出弯没给油，这一下慢了 14 秒」。

== 更新速览 ==

采集    新增方向盘转角、三轴 G 力、世界坐标、车头朝向
分析    弯道识别从「按速度下降」改成「按曲率」
        弯道数量直接对齐官方弯数
        自动检测 spin / 打滑（正常刹车不会误报）
        时间损失按 100 米归因
报告    圈速与一致性 / 失误定位 / 逐弯对比 / 改进建议
        检出错误会主动问「想不想深挖」
新图    赛道轨迹诊断图：你跑的线 + 弯位编号 + 问题标注
修复    3 个隐蔽 bug（见下文）

== ① 数据更全了 ==

以前只有：速度、油门、刹车、档位。
现在多了：方向盘转角、三轴 G 力（横向/纵向/垂直）、世界坐标、车头朝向。

多了这些，才有后面三件事：
· 有车头朝向 → 能算弯道曲率
· 有世界坐标 → 能画出你跑的轨迹
· 有横向 G   → 能认得出打滑失控

== ② 弯道识别换了算法 ==

旧方法按「速度下降」找弯：S 弯会粘成一段、高速全油弯根本找不到，弯数在 14~20 个之间飘。

0.2.3 改按曲率找：κ = dψ/ds（车头朝向的变化率），保留左/右符号，S 弯天然断开。
再加上「官方弯数」当硬约束 —— 银石 18 个弯，一个不差。
多圈数据按赛道距离对齐后取平均，单圈走线差异和噪声互相抵消。

== ③ 会看你的失误了 ==

判据：速度断崖 + 横向 G 塌陷，两个条件同时成立才算失控。
只卡速度会误报 —— 正常重刹也能掉 40~50 km/h，所以阈值专门调过。
检出后定位到第几米、第几弯，并归因到 100 米段。

== ④ 会画你的轨迹 ==

用你跑出来的世界坐标画成赛道形状，18 个弯标上编号。
颜色分级：红 = 失控，橙 = 各圈差异大，灰 = 跑得稳。
标注带方向：`方向 多打 −0.36`（打多了要收）、`给油 晚 −125 m`（晚了要提前）。
报告里说「第 13 弯」，图上就是第 13 个点，一眼对上。

== ⑤ 它会主动问 ==

捡到失误后报告会直接说：「想知道这一下怎么发生的、下次怎么避免吗？」
你说想，它就把这一圈和最快圈逐秒拉出来对比：哪一脚刹车踩重了、哪一次方向打多了。
不用你自己猜要问什么。

== 修了 3 个隐蔽 bug（技术向）==

1. Motion 包字段偏移：F1 22+ 的 CarMotionData 里方向向量是 int16 不是 float，
   之前把 yaw 当成了横向 G（表现：直道也不归零、范围正好 ±π）。
2. lapDistance 偏移 @16 → @20、lapNum @25 → @33（F1 24/25 的 LapData 57 字节布局）。
3. 采集器被宿主进程树回收：会话空闲几分钟就没了，日志还一条线索都没有。
   改成 detached 运行 + 日志落盘 + 记录退出码。

== 已知限制（说实话）==

· 目前只有银石完成弯位校准（18 个弯），其他 23 条赛道弯数还没填，识别会不准
· 弯位是从你的实际走线反推的，不是官方中心线，误差几十米
· 只支持 F1 25 的 2025 赛制 UDP 格式
· 同时只能跑一个采集任务

为什么其他赛道还没做：弯位必须用实跑数据校准，不能凭空填 —— 公开资料只有弯名和全长。
哪条赛道跑过就能校准，想让我做你常跑的那条，评论区说一声。

== 下一步 ==

· 理想圈：把各段最好表现拼起来，看理论上能跑多少
· 剩下 23 条赛道的弯位校准
· 跟 AI 车手遥测对比（AI 在这个弯比你快多少）
· 再往后：神力科莎竞速、神力科莎适配

== 安装 & 使用 ==

1. DSH 设置 → 插件 → 填 https://github.com/jingjie43/dsh-sim-telemetry → 重启
2. 设置页一键装 Python 3.12（没装的话）
3. F1 25 → 设置 → 遥测：UDP 开、广播关、端口对上（默认 20777）、格式 2025
4. 插件里选圈数 → 点开始记录 → 正常跑

跑满圈数自动停，自动出：
文字摘要 / laps_*.csv / summary_full_*.md / 速度图 / 油门图 / 轨迹诊断图 / 工程师报告

GitHub：https://github.com/jingjie43/dsh-sim-telemetry
开源免费，欢迎 star 和提 issue。
```

| 会问 | 怎么回 |
|---|---|
| 「支持神力科莎 / ACC 吗」 | 现在只支持 F1 25。ACC、AC 在计划里，架构上换个采集适配器就行，但要一个个来 —— 先把手上的打磨好。 |
| 「我跑的赛道弯数不对」 | 正常，目前只校准了银石。弯位必须用实跑数据校准，不能凭空填。你跑两圈把赛道名告诉我，我下一版加。 |
| 「怎么装 / Python 报错」 | 设置页有一键安装 Python 3.12。还不行把 `~/.dsh/sim-telemetry/debug.log` 发我看看。 |
| 「能装在 PS5 / 主机上吗」 | 不行，主机不开放遥测数据。只能在 PC 上用。 |
| 「和 Motec 有什么区别」 | 它给你一堆曲线你自己读；这个直接告诉你该改什么。数据全本地，不上传。 |
| 「数据会上传吗」 | 不会。采集和分析全在本机 Python 里跑，AI 只读结论。 |
| 「理想圈什么时候有」 | 下个版本优先做，数据已经齐了。 |
| 「多久更新一次」 | 看空余时间，有实跑数据就进步得快。想推哪条赛道可以催我。 |
