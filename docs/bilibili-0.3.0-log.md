## 二、更新日志正文（长版 · 发专栏 / 动态图文）

> 标题：**dsh-sim-telemetry 0.3.0 更新：第三条赛道「斯帕」+ 历史记录管理**

```
0.2.4 的时候，它只有两条赛道的弯位数据。
0.3.0 做了两件事：加上第三条赛道（斯帕），并且你跑过的每一圈都能在设置页里翻出来对比。

== 更新速览 ==

赛道    斯帕 Spa 19 个弯校准完成，含官方弯名
数据    设置页新增「历史记录」：所有采集按赛道 / 时间 / 圈数列出来
对比    勾选 2 份以上 → 速度曲线叠加 / 逐弯改进表并排
出图    勾选 1 份 → 6 种图一键生成（速度 / 油门 / 轨迹诊断 / 赛道图 / 弯位表 / 逐弯细节）
修复    长赛道后段丢失的 bug（斯帕 Blanchimont / Bus Stop 之前识别不出来）
作者    设置页加上作者信息：B站「静戒」· UID 544228946

== ① 第三条赛道：斯帕（Spa-Francorchamps）==

和蒙扎一样，用三份实跑数据交叉验证（三取二，每弯位置差 ≤40 米），
19 个弯全部对上 F1 官方弯名：

La Source / Eau Rouge ×2 / Raidillon / Les Combes ×2 / Malmedy / Bruxelles /
Jacky Ickx Curve / Pouhon ×2 / Fagnes ×2 / Campus / Curve Paul Frere /
Blanchimont ×2 / Bus Stop ×2

现在插件支持 12 条赛道：银石（18 弯）、蒙扎（11 弯）、斯帕（19 弯）、巴林（15 弯），全部带官方弯名或编号。

== ② 历史记录：跑过的圈不再散落 ==

以前跑完的数据就是一堆文件躺在目录里，想找回上周那次的对比，只能自己翻。
现在设置页多了「历史记录」：

· 按赛道分组，显示每次采集的时间、圈数、最快圈、每圈时间
· 勾选任意多份 → 打包成 zip（原始数据 + 图 + 报告一起带走）
· 勾选后可以删除（会二次确认，删了就没了）
· 数据全在本机，不上传

== ③ 一键出图：6 种图随便点 ==

以前想看某张图，得在对话里问一句才生成。
现在选中一份采集，下面直接有 6 个按钮：

· 速度曲线       三圈速度叠加，最快圈高亮
· 油门刹车       最快圈的油门 / 刹车曲线
· 轨迹诊断       你跑的线 + 弯位编号 + 失误标注（方向打多/打少、给油早晚）
· 赛道图         弯位编号 + 官方弯名图例
· 弯位表         每弯的入口 / apex / 出口 / 方向 / 半径 / apex 速度
· 逐弯细节       每个弯一个小面板，三圈速度曲线叠在一起，看哪个弯不稳一目了然

== ④ 多份采集对比 ==

勾选 2 份以上数据：

· 对比速度曲线：按赛道距离对齐，两份采集的最快圈叠在一张图上
· 对比逐弯改进表：19 个弯 × N 份采集并排，每个弯的最优 apex 速度直接横向比

适合「今天 vs 昨天」「这次调校 vs 上次」这种对比。

== ⑤ 修了一个藏得很深的 bug ==

插件里原本写死了一个「赛道长度 5890 米」（那是银石的长度）。
斯帕实际 7007 米，导致后 1000 多米（Blanchimont 和 Bus Stop 两个弯）的数据被整段丢掉，
第一次分析斯帕时那两个弯根本识别不出来。

现在改成按游戏给的赛道长度自动判断。银石、蒙扎不受影响。

== ⑦ 成绩单 + 逐弯 apex 对比：挑几圈出来比 ==

以前报告只给「这一次」的结果。现在可以把**你跑过的任意几圈**拉出来横着比：

· 在历史记录里勾选多份采集（勾 1 份 = 3 圈，勾 2 份 = 6 圈）
· 也可以填圈号（比如 1,3,5）只比这几圈
· 一键生成两张图：
  - **成绩单**：圈速 / 极速 / 均速 / 全油 / 滑行 + 自动问题标注
  - **逐弯 apex 对比**：每个弯，每一圈的 apex 速度并排，差多少一目了然

== ⑥ 直道漂移检测：直线上到底飘不飘 ==

有个车友的疑问很有代表性：「我跑直线的时候总感觉车在飘。」
现在报告能直接回答这个问题——

做法：把所有高速直道（>280 km/h 的段落）找出来，用世界坐标拟合一条直线，
计算你实际跑线相对这条直线的横向偏移：

· 偏移 > 0.5 米 → 报告里单独列出来
· 同时给出「方向盘抖动」——如果偏移大但方向盘几乎没动，说明是车/路面在飘，不是你的手在晃

实测例子（巴林主直道）：横向偏移最大 3.34 米，方向盘抖动只有 0.01 ——
车确实在飘，但方向盘操作是对的。

== ⑦ 第四条赛道：巴林（Bahrain）==

巴林官方 15 弯（Turn 1-15，没有传统弯名），三份实跑数据三取二校准完成。
现在支持四条赛道：银石 18 / 蒙扎 11 / 斯帕 19 / 巴林 15，全部带官方编号或弯名。

== 已知限制（说实话）==

· 目前 12 条赛道（211 弯）完成弯位校准
· 其余 12 条赛道弯数还没填，识别会不准，会一条条补
· 弯位是从你的实际走线反推的，不是官方中心线，误差几十米
· 只支持 F1 25 的 2025 赛制 UDP 格式
· 同时只能跑一个采集任务

哪条赛道跑过就能校准，想让我做你常跑的那条，评论区说一声。

== 下一步 ==

· 剩下 20 条赛道的弯位校准
· 逐弯改进表做成图片（现在是文字表格）
· 单圈删除（现在删除是按采集整份删）
· 再往后：生涯模式数据（轮胎管理、ERS 策略）、AI 车手对比、神力科莎适配

== 安装 & 使用 ==

npm 一条命令：
  dsh plugin --profile web add dsh-sim-telemetry

或从 GitHub Release 下载 tgz 本地安装。
装完重启 DSH，设置左侧出现「赛车遥测」。

然后：
1. 设置页一键装 Python 3.12（没装的话）
2. F1 25 → 设置 → 遥测：UDP 开、广播关、端口对上（默认 20777）、格式 2025
3. 插件里选圈数 → 点开始记录 → 正常跑

跑满圈数自动停，自动出报告和图。

GitHub：https://github.com/jingjie43/dsh-sim-telemetry
开源免费，欢迎 star 和提 issue。
```

## 八、评论区答疑模板

| 会问 | 怎么回 |
|---|---|
| 「支持神力科莎 / ACC 吗」 | 现在只支持 F1 25。ACC、AC 在计划里，架构上换个采集适配器就行，但要一个个来 —— 先把手上的打磨好。 |
| 「我跑的赛道弯数不对」 | 正常，目前只校准了银石、蒙扎、斯帕三条。弯位必须用实跑数据校准，不能凭空填。你跑两圈把赛道名告诉我，我下一版加。 |
| 「怎么装 / Python 报错」 | 现在有 npm 一条命令：`dsh plugin --profile web add dsh-sim-telemetry`。Python 没装的话设置页有一键安装。还不行把 `~/.dsh/sim-telemetry/debug.log` 发我看看。 |
| 「历史记录会占很多空间吗」 | 一份采集大概 1.5~2 MB（原始遥测），觉得多了可以在列表里删掉旧数据。 |
| 「数据会上传吗」 | 不会。采集和分析全在本机 Python 里跑，AI 只读结论。 |
| 「逐弯改进表什么时候有图片版」 | 下个版本做，现在表格是文字版。 |
| 「能删单圈吗」 | 现在删除是按采集整份删（一次 3 圈一起）。单圈删除在下个版本。 |
| 「多久更新一次」 | 看空余时间，有实跑数据就进步得快。想推哪条赛道可以催我。 |
